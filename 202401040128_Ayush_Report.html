1. Aim and Problem Statement

1.1 Aim

To design and develop a single-page responsive e-commerce web application inspired by Amazon.in using HTML5 semantic tags, modern CSS3 (Flexbox, CSS Grid, media queries), and Bootstrap 5 components, and deploy the application within the webapps directory of an Apache Tomcat servlet container.

1.2 Problem Statement

Modern e-commerce platforms must provide an intuitive, high-performance, and responsive user interface across desktops, tablets, and mobile smartphones. The objective is to implement:

  • Semantic Structure: Header with location and search bar, sub-nav categories, hero promotional carousel, 4-grid category cards, deals flexbox scroller, and 4-column footer.
  • Styling & Responsiveness: CSS Custom Properties, Flexbox for 1D alignments, CSS Grid for 2D catalog layouts, and fluid media queries across mobile (<576px), tablet (576px–991px), and desktop (>992px).
  • Dynamic Single-Page Features: Dynamic cart state with badge counter, slide-in offcanvas cart drawer, live debounced search filter, category filter pills, quick-view modal, and toast alerts.
  • Tomcat Deployment: Full deployment inside Apache Tomcat 10 and resolving local port binding conflicts.

4. Apache Tomcat Deployment Process

  1. Directory Deployment: Deployed source files (index.html, css/, js/, images/) to apache-tomcat-10.0.23/webapps/amazon/.
  2. Runtime Configuration (bin/setenv.bat): Bound Java JDK 21 LTS: 
    set "JAVA_HOME=C:\Program Files\Java\jdk-21"
set "JRE_HOME=C:\Program Files\Java\jdk-21"
set "CATALINA_HOME=C:\Users\ayush\apache-tomcat-10.0.23"
  3. Port Conflict Resolution: Standard port 8080 was in use by Oracle XE XML listener (TNSLSNR / DAV). Configured Tomcat's HTTP Connector to port 8081 inside conf/server.xml.
  4. Execution & Verification: Started server using catalina.bat run. Application served live at:
    http://localhost:8081/amazon/

7. Conclusion & Learnings

7.1 What Works

  • High visual fidelity reproducing Amazon.in’s look, feel, typography, and color palette.
  • 33 self-contained, lightweight vector SVG assets in images/ ensuring 100% offline functionality.
  • Responsive layout tested across desktop, tablet, and mobile devices without horizontal overflow.
  • Dynamic client-side features: Shopping cart state, live search, category filtering, quick-view modal, countdown timer.
  • Successfully deployed and served from Apache Tomcat 10.0.23 webapps directory.

7.2 Limitations

  • Client-side cart state resets on page refresh; requires backend database/session storage for persistent user sessions.
  • Payment gateway triggers a checkout simulation rather than live banking transaction APIs.

7.3 What I Learned

  • How to integrate CSS Grid for 2D spatial layouts with Flexbox for 1D inline alignment.
  • How to customize and extend Bootstrap 5 components (Carousel, Offcanvas, Modal, Toast) with custom CSS variables.
  • Practical server administration: configuring Apache Tomcat, handling environment variables (JAVA_HOME, CATALINA_HOME), and resolving port collisions (Oracle XE port 8080 coexistence).
